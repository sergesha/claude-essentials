# Authoring Simplify-With-Write Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Preserve automatic recipe/template authoring and every accepted containment/canonical-admission control while replacing the crash-atomic multi-file journal/recovery transaction with one bounded, serialized, per-file atomic writer.

**Architecture:** Eight focused authoring modules own immutable plans, bounded capture, child-first compilation, canonical admission, descriptor-relative containment, and a small publisher. The publisher reuses the existing project namespace and `transaction.lock`, refuses every legacy `transaction.json`, performs whole-bundle preflight, and atomically replaces one target at a time without rollback or a new persistence lifecycle. Runtime start observes the same lock boundary and admits a freshly observed generated closure if and only if every planned artifact and exact recipe DAG are canonical.

**Tech Stack:** Python 3.12, pytest, POSIX `fcntl.flock`, descriptor-relative `openat` operations through Python `dir_fd`, YAMLGraph 0.5.22, LangGraph 1.2.10.

**Spec:** `.superpowers/reviews/2026-08-29-task-12a5-proportionality.md`

**Threat model:** `.superpowers/specs/2026-08-20-lockstep-threat-model.md`, especially SI-02, SI-04, SI-20, SI-25, SI-26, the Local unsandboxed single-user profile, the authority-delta rule, and the stop rule.

## Global Constraints

- Preserve the installed CLI/MCP/template behavior: automatic `recipe init`, `recipe compile`, and template installation; exact existing stdout, exit codes, MCP dictionaries, template catalog, role order, collision type, generated bytes, manual-recipe behavior, render output, and estimate schema.
- Final authoring production surface MUST be at most 2,200 physical lines in at most 10 modules; this plan targets exactly 8 modules capped at 1,940 physical lines.
- Final focused authoring tests MUST be at most 3,200 physical lines; this plan targets 15 focused files capped at 2,980 physical lines.
- Remove at least 2,647 production and 5,643 test lines; this plan removes 2,907 production and 5,863 test lines.
- Create no durable schema, journal/version, recovery state machine, lifecycle owner, scheduler, manager, cursor, lock family, compatibility alias, or StrEnum work.
- Preserve the exact existing namespace digest and `$LOCKSTEP_STATE_DIR/authoring/<digest>/transaction.lock`; use `lockstep.runtime.advisory_lock.advisory_file_lock` as the sole authoring lock primitive.
- Under that lock, any `transaction.json` blocks every state-aware public
  operation: recipe/template writes, recovered check/diff, CLI and MCP
  check/diff/render/estimate, and runtime admission. It receives guidance that
  it may be v4, must be recovered with a pre-simplification build against the
  same project/state directory, and must not be deleted manually. Therefore a
  real v4 fixture receives actionable guidance while malformed, unknown, v2,
  and v3 content follows the identical fail-closed path. The simplified build
  does not parse, recover, migrate, rewrite, or remove the file. Pure
  state-directory-free library functions (`check_recipe`, `diff_recipe`,
  `render_recipe`, `estimate_recipe`) remain deterministic filesystem
  projections and are explicitly not owner-state boundaries; installed CLI/MCP
  entry points always wrap them with `observe_authoring_project`.
- Before any project mutation, perform complete source, limit, project/parent identity, exact before-image/absence, containment, duplicate-target, cross-role collision, and all-destination collision preflight.
- Immediately before every target mutation, revalidate the complete captured source closure, exact target before-image/absence, regular-file shape, parent identity, and descriptor-relative no-follow containment.
- Write a same-directory live-owned temporary with `O_CREAT|O_EXCL|O_NOFOLLOW`; verify regular shape; write all bytes; chmod; fsync; publish absent targets with a no-clobber link and present targets with a same-directory replace; verify exact after bytes/mode; fsync the target and parent.
- On failure or process death, never roll back earlier targets or remove previously created directories. Clean up only a temporary whose inode is still proven owned by the live invocation.
- Crash admission oracle: real public runtime start succeeds if and only if its entire freshly observed generated closure and exact DAG are canonical. A pre-mutation cut may leave the old canonical closure startable. Any incomplete or mixed closure fails before durable run creation, effect creation/dispatch, checkpoint/native continuation, or recipe-bundle admission.
- Preserve all non-authoring runtime watch, publication, effect, owner-authority, checkpoint, CAS, stale-sidecar lock, global locking, and provider behavior unchanged.
- The eight capped `authoring*.py` modules are the audited authoring production
  population. `templates/__init__.py`, `template_installation.py`,
  `runtime/service.py`, `cli.py`, and `mcp/server.py` are fixed integration
  consumers outside that count; their combined net line growth in this range
  MUST be at or below zero and they acquire no new responsibility or lifecycle.
- No production authoring file may exceed 350 physical lines. A function at or
  above 80 physical lines emits an SRP-review warning but never fails on length
  alone. Cyclomatic complexity MUST be at most 15, cognitive complexity at
  most 25, nesting at most 4, and unique call fan-out at most 24.
- Every production microcycle requires an independent spec-compliance and quality review before the next microcycle. The complete range requires independent product/proportionality, architecture/SRP, and threat/reliability reviews with Critical/Important/Minor findings all zero.
- Every task commit is local only. Do not push, publish, open a PR, or continue to Task 12C in this range.

def _authoring_functions() -> tuple[tuple[str, str, ast.AST], ...]:
    found: list[tuple[str, str, ast.AST]] = []
    for path in sorted(SOURCE_ROOT.glob("authoring*.py")):
        tree = ast.parse(path.read_text(encoding="utf-8"))

        class LexicalFunctions(ast.NodeVisitor):
            def __init__(self) -> None:
                self.prefix: list[str] = []

            def visit_ClassDef(self, node: ast.ClassDef) -> None:
                self.prefix.append(node.name)
                self.generic_visit(node)
                self.prefix.pop()

            def _visit_function(self, node: ast.FunctionDef | ast.AsyncFunctionDef) -> None:
                qualified = ".".join((*self.prefix, node.name))
                found.append((str(path.relative_to(SOURCE_ROOT)), qualified, node))
                self.prefix.append(node.name)
                self.generic_visit(node)
                self.prefix.pop()

            visit_FunctionDef = _visit_function
            visit_AsyncFunctionDef = _visit_function

        LexicalFunctions().visit(tree)
    return tuple(found)
