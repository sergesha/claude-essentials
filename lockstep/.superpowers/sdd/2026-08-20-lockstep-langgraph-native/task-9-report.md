## Architecture delivered

`ResolvedCatalog` now contains immutable, I/O-free compiled child bundles and
typed closed fragment IR. A child call specializes the complete direct and
transitive source DAG deterministically, binds its path and bytes to the parent
source, preserves standalone topology, and emits one native yamlgraph
`mode: direct` node. There is no child process runtime, scheduler, credential,
ancestry store, public child row, or Task 10 artifact store.

Call lowering creates compiler-owned, collision-checked scope, request/result,
outcome, contract bridge, and saved parent-context channels. Only declared typed
inputs and exports cross the boundary. Nested protected effects resolve state
from the exact checkpoint namespace owning their interrupt, so parallel
subgraphs are never flattened into an ambiguous root map. Nested deadlines are
the minimum of ancestor and local scopes, the innermost declared runner wins,
and runner binding remains exact and pre-spawn checked by the coordinator.
PASS, FAIL, ERROR, and ABORTED route explicitly; parent execution context is
restored on an unconditional bridge after child outcome selection.

Compilation results bind the exact root and generated file set, canonical
dependency manifest, complete direct/transitive read set, and ingress-canonical
execution bytes. The final compiler gate materializes that exact bundle in a
private temporary directory, runs `StrictRecipeIngress` aggregate limits and
closed DAG admission, requires exact canonical reachable-file equality, then
runs recursive profile/provenance checks and a real yamlgraph compilation.
Freshness compares root bytes, generated bytes, and dependency-manifest bytes.

Inline and included fragments share one closed `FragmentIR`: passthrough plus
protected interrupts only, safe typed flat state, deterministic hashed
namespaces/identities, exact declared-write union, declared and exhaustive
outcome routing, reachable unique exits, and locally bounded cycles. Lowering
does not synthesize missing outcome routes. Protected result channels cannot be
overwritten by passthrough nodes; every scope/result selector is declared dict
state. Nested include/subgraph and executable yamlgraph escape hatches fail at
compile time.

Native status exposes only an opaque correlation `child_run_id` derived from the
parent run and stable public native task coordinate. It is not a run ID: catalog,
status, history, and scenario completion reject it, no child row exists, and no
checkpoint namespace is disclosed. Sync SQLite restart, real memory async
`aresume`, nested different-runner/deadline/input behavior, and the full shipped
daily plan→tests→implement→verify→review recipe are covered.
